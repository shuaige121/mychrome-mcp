FAQ

常见问题

客户端支持、登录状态、隐私、控制方式和网站适用范围。

MyChrome 是什么？

MyChrome 是本机 MCP server 和原生 macOS App。你照常使用 Chrome，需要时让 AI 在同一页帮你做事；需要本人操作时交回控制，收到你的继续指令后再接着原任务。它使用真实鼠标和键盘，支持调整操作速度和可选的个人节奏采样。

支持哪些电脑和客户端？

支持 Apple Silicon Mac、macOS 13+、Google Chrome，需要受支持的 Node.js 和 Xcode Command Line Tools。Codex 和 Claude Code 都能使用浏览器工具；其他本机 stdio MCP 客户端可用生成的路径连接。原生窗口的实时文字和回复需要支持的 Codex 集成与已关联会话，Claude 暂不支持这两项功能。

能用我现有的登录状态吗？

可以，操作发生在你的 Chrome 中。告诉助手使用哪个现有标签页，变更前确认网站显示的账号。Chrome profile 和网站账号不一定是同一个身份。

每个网站都能用吗？

实际能力取决于网站控件、账号权限和页面状态。登录或网站验证可能需要你接手。网站上的任务示例是需求说明，不是所有相关流程已经验证的兼容性承诺。

能按我的操作习惯来吗？

可以选择输入方式和 0.5×–3× 的操作速度。“我的操作习惯”还提供可选的 3 分钟个人节奏采样，用样本足够的打字与指针统计调整后续输入。采样是实验功能，可以关闭使用或删除数据；仅保存本机统计摘要，不保存输入内容、原始轨迹或截图。

我接手之后，AI 怎么继续？

交接提示会要求 AI 等待你的继续指令。处理完后，在原对话告诉它继续，AI 再读取页面核对。页面变化或输入完成的检测只表示观察结束；后续操作由 AI 客户端遵守交接指令。

怎么停止 AI？

在 0.8 秒内连按两次 Esc，取消当前 AI 并收回键鼠。AI 需要你的新指令才能再次接管。收回控制后，打开“暂停 AI 操作”可阻止所有连接继续输入。停止不会撤销已发出的操作。

AI 操作时，我能使用鼠标吗？

接管期间普通物理输入会被拦截。桌面只有一套真实鼠标和键盘，多个 AI 的输入依次进行；读取可以并行。需要接手时使用双 Esc。

数据保存在什么地方？

MyChrome 的设置、操作记录和网站流程元数据保存在本机。流程记录默认开启，可以关闭；记录筛选后的页面与控件描述及操作顺序，不把输入正文和选项值保存为重放默认值。路径、标签和流程名仍可能反映使用情况。通过 MCP 返回的页面内容会交给 AI 客户端，并按其设置处理。不要公开运行目录或账号截图。

网站流程是什么？

把符合条件的连续操作保存下来。每次运行先检查步骤、填写新参数并明确选择现有标签页。运行仍使用原有输入保护，步骤之间不调用模型；页面或目标不匹配时停止。它不支持所有控件，完成步骤也不代表外部业务一定成功。

免费吗？

MyChrome 采用 MIT License 开源。模型访问由 AI 客户端提供，其费用或订阅可能另计。当前版本通过源码安装，未发布到 npm。

所有网页都需要用 MyChrome 吗？

公开信息通常可以直接用 API 或 web fetch；不依赖现有登录的 JavaScript 页面可用 headless browser。工作依赖当前 Chrome 上下文，或需要和助手共用同一个页面时，适合使用 MyChrome。

一定能节省 token 吗？

没有统一的节省保证。页面读取可以返回提纲和局部文字，而不总是使用整页或图片；实际用量取决于页面、客户端和任务。

准备开始？

接上你正在使用的 Chrome，从手头的事开始。
