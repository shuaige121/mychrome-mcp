你的 Chrome · 你的节奏

你的 Chrome，
随时多一双手。

MyChrome 是本机运行的 MCP server，带原生 macOS app。它让 Codex、Claude Code 和其他本机 stdio MCP 客户端在你正在使用的 Google Chrome 中操作，沿用现有标签页、已登录账号及真实鼠标和键盘。

面向需要自己的 Chrome 登录状态、现有标签页，或与助手在同一页面协作的 Mac 用户。

什么时候使用 MyChrome，什么时候使用其他浏览器工具

公开页面和 API

公开信息优先使用 API 或 web fetch。

无需登录的 JavaScript 页面

页面不需要你的登录会话时，优先使用 headless Playwright。

你自己的 Chrome、登录状态或共享页面

任务需要现有标签页、已登录账号，或你与助手正在协作的同一页面时，使用 MyChrome。

限制自动化访问的网站

能否完成取决于网站、账号权限和当前页面。遇到 CAPTCHA 或机器人检查时，MyChrome 停止并交给你处理，不会代为解决；遇到拒绝访问或限流，助手应停止并报告。

控制权在你手里

你和 AI，
轮流接着做。

助手使用 Mac 的真实鼠标和键盘；接管卡片显示任务、每一步和剩余时间。接管期间，普通实体输入会被拦截。遇到 CAPTCHA 或机器人检查时，MyChrome 停止并交给你处理，不会代为解决。

esc+esc

想接手，快速连按两次 Esc。

在 0.8 秒内连按两次 Esc，停止当前 agent 并取回键鼠。再次接管需要新的指令。MyChrome 的暂停控件可阻止所有连接继续输入。停止不会撤销已经发送的操作。

0.15.0 新增

0.15.0 新增功能。

以下功能已随 0.15.0 于 2026-11-07 发布。

Claude Code 对话镜像

0.15.0 中，连接 MyChrome 的终端 Claude Code 会话会显示为只读镜像，包含连接后的提问和 Claude 回复文字。接管期间，侧栏显示 Claude 回复文字，不显示思考、工具调用或工具结果。你仍在终端回复，MyChrome 不会向终端输入。镜像文字仅保留在内存中，不写入日志或文件。默认开启；在 MCP server 环境中设置 CHROME_BRIDGE_CLAUDE_FEED=0 并重新连接 MCP 客户端即可关闭。

焦点处理

0.15.0 中，Google Chrome 不在前台时，MyChrome 会在操作前将它带到前台，根据指针落点及每次按键前检查的页面键盘焦点判断。如果仍不能操作，会及时返回，说明此前前台是什么以及是否已发送操作。

文字识别等待有时限

0.15.0 中，如果文字识别较慢，截图会在识别启动约 8 秒后返回，包含图像及文字尚未就绪的说明。后台预热启动前会检查是否正在输入；检测到输入时会推迟启动。

使用你已经打开的页面

0.15.0 中，当你让助手处理已打开的页面或自己的 Google Chrome 时，MyChrome 的指令会要求它优先使用那个确切标签页，再考虑其他浏览器工具。请重新连接 MCP 客户端以接收新指令。

MyChrome 使用你的语言

0.15.0 中，MyChrome 的窗口和通知跟随 Mac 的语言（英文或中文），也可在菜单栏面板的设置中选择界面语言；接管卡片及侧栏同样跟随。也可设置 CHROME_BRIDGE_UI_LANG=en|zh；面向助手的工具文字不变。
