GETTING STARTED

Connect the Chrome you already use.

MyChrome is a local MCP server with a native macOS app. It lets Codex, Claude Code and other local stdio MCP clients work in the Google Chrome you already use, with your existing tabs, signed-in accounts and real mouse and keyboard.

Before you start: check your Mac

Codex and Claude Code can use the browser tools; other local stdio MCP clients can connect with the printed paths. You need an Apple Silicon Mac with macOS 13+, Google Chrome in /Applications, native arm64 Node.js 24+ recommended (20.19+ and 22.13+ also supported), Git and Xcode Command Line Tools. Intel Macs, Rosetta Node, Windows, Linux and other browsers are not supported. MyChrome runs on the Mac whose Chrome it controls.

1. Install MyChrome from source

Choose a permanent folder for the checkout, then run:

git clone https://github.com/shuaige121/mychrome-mcp.git
cd mychrome-mcp
bash scripts/setup.sh

Setup checks prerequisites, installs dependencies, builds native helpers, installs the app in ~/Applications and checks permissions. It does not change your AI client’s configuration or grant macOS permissions. Keep the checkout in place; the app and MCP client use it. MyChrome is not published to npm.

Use bash scripts/setup.sh --check for a check only, or --app-path for a separate installation. Install missing Xcode Command Line Tools with xcode-select --install. The bilingual first-run guide can be reopened with the question-mark button.

2. Allow access and connect your AI client

Enable Google Chrome’s Allow JavaScript from Apple Events setting. MyChrome needs no extension, remote debugging port or separate browser profile.

Allow macOS permissions

  • Automation → Google Chrome: read and control Chrome.
  • Accessibility: real mouse and keyboard input.
  • Screen Recording: screenshots and text recognition.
  • Input Monitoring: only for optional habit sampling.
node src/index.js doctor

The check reports permissions; --ask requests the Automation prompt and --open opens the settings page.

Connect Codex or Claude Code

bash scripts/setup.sh --instructions

Use the printed connection commands for Codex or Claude Code, or the printed paths for another local stdio MCP client. For Codex, apply startup_timeout_sec = 30 and tool_timeout_sec = 900 to the printed MyChrome entry.

3. Return to your conversation and continue the task

In your existing AI conversation, name the page by title or URL and describe the outcome you want. The assistant reads the page first, acts within your authorization and checks the result.

Example requests, not verified case studies: update your LinkedIn page with details you provide; check Facebook messages and notifications for people trying to reach you; publish an article you wrote to specified Facebook, Xiaohongshu, Reddit or LinkedIn accounts. Compatibility depends on the site, account permissions and current page.

For passwords or verification codes, take over. Explicitly say “continue” in the original conversation; the assistant should reread the page before resuming. Continuation follows the assistant’s instructions; MyChrome does not enforce a cross-client continuation gate.

At a CAPTCHA or bot check, MyChrome stops and hands over; it does not solve it. On access denial or rate limits, the assistant should stop and report. Press Esc twice within 0.8 seconds to stop the current agent; stopping does not undo actions already sent.

Make the input pace yours

Choose follow-task, key-by-key or paste input, with typing, pointer and scrolling speed from 0.5× to 3×. Use paste for Chinese or other text key-by-key input cannot type. Optional personal input habit sampling is experimental: a 3-minute sample supplies timing statistics for later input; values without enough samples keep defaults. You can turn it off, resample or delete it. Only a local statistical summary is stored: no keys, typed text, screen coordinates, window or app names, or screenshots; raw events are never written to disk. It is not a behavioural clone and does not guarantee a site will accept automation.

Input Monitoring permission is needed only for optional sampling. The input controls are in Operation settings, the middle part of the switch at the top of the MyChrome window. English control labels refer to 0.15.0 with English selected.

Your controls

In 0.15.0, MyChrome’s windows and notifications follow your Mac’s language (English or Chinese), with a Language setting under Settings in the menu bar panel. You can also set CHROME_BRIDGE_UI_LANG=en|zh. Agent-facing tool text does not change.

New conversation is at the top left (⌘N). The three-part switch contains Conversations, Operation settings and Website routines. Pause AI operations is at the top right; the question-mark button opens Getting started.

Press Esc twice within 0.8 seconds to stop the current agent and regain the mouse and keyboard. A new instruction is needed before another takeover. Stopping does not undo actions already sent. The pause control blocks further input from every connection. During takeover, ordinary physical input is intercepted; the takeover card shows the agent, task, checklist, time left and speed. Physical actions from several agents queue for one pointer and keyboard; page reads can run together.

Conversations in MyChrome

Yes. New conversation (⌘N) starts a separate conversation with an installed, signed-in CLI, a model from that CLI, a supported reasoning effort and a working folder; the first task is optional. These choices do not rewrite client configuration. App-created conversations show live text, follow-up replies and supported questions or approval requests. Stop generation interrupts them. Closing the app leaves them running; reopening rejoins them while the backend process is alive, with no automatic recovery after it exits. An existing Codex conversation needs a supported local integration and an associated thread.

In 0.15.0, a terminal Claude Code session connected to MyChrome appears as a read-only mirror of your prompts and Claude’s reply text from connection time. During takeover, the sidebar shows Claude’s reply text. Thinking, tool calls and tool results are not shown. You reply in the terminal; MyChrome never types into it. Mirror text stays in memory and is not written to logs or files. It is on by default; set CHROME_BRIDGE_CLAUDE_FEED=0 in the MCP server’s environment and reconnect the MCP client to turn it off.

Page content and website routines

MyChrome runs locally, and screenshots and text recognition run on the Mac using Apple Vision. Page content returned through MCP goes to your AI client and is handled under that client’s settings. Website routine recording of local action metadata is on by default and can be turned off. Typed and selected values are not saved as replay defaults. Local records and routine metadata may reveal which sites you use; keep runtime records private.

Saved sequences replay with fresh values on a tab you select, without model calls between steps. They stop when the page or target no longer matches. Routine completion is not proof of a business outcome.

Troubleshooting

Check the requirements above if your Mac or Node.js build is unsupported. Run xcode-select --install for missing Command Line Tools. Use node src/index.js doctor to check permissions and bash scripts/setup.sh --instructions to print connection commands.

For Codex, check startup_timeout_sec = 30 and tool_timeout_sec = 900. Use paste for text key-by-key input cannot type. At access denial or rate limits, stop and report the restriction.

When to use MyChrome vs. other browser tools

Public pages and APIs

Use an API or web fetch first for public information.

JavaScript pages without a login

Use headless Playwright first when the page does not need your signed-in session.

Your own Chrome, login or shared page

Use MyChrome when the task needs your existing tabs, signed-in accounts or a page you and your assistant are working on together.

Sites that block automation

Website compatibility depends on the site, account permissions and current page. At a CAPTCHA or bot check, MyChrome stops and hands over; it does not solve it. On access denial or rate limits, the assistant should stop and report.
