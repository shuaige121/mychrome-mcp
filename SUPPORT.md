# Getting help

Start with [setup and troubleshooting](docs/getting-started.md#troubleshooting) or the [FAQ](docs/faq/README.md). 中文用户可查看[首次使用指南](docs/getting-started.zh-CN.md)。

For a reproducible problem, [open a GitHub issue](https://github.com/shuaige121/mychrome-mcp/issues/new/choose). Include:

- MyChrome release, macOS version, Apple Silicon model, Node version and AI client.
- The smallest steps that reproduce it, preferably on the included local practice page.
- Expected behavior, actual behavior and the exact sanitized error message.
- Whether `bash scripts/setup.sh --check` or `node src/index.js doctor` identifies a missing requirement.

Review diagnostic output before sharing. Remove personal paths, website account details, page content and tokens. Do not upload browser profiles, conversations or runtime data directories.

Report vulnerabilities through the [private security channel](SECURITY.md). Community support has no guaranteed response time.
