# MyChrome launch kit

## One sentence

MyChrome lets your AI assistant help in the Chrome you already use on your Mac, with your existing pages, real mouse and keyboard input, and an easy way to take control back.

## Short introduction

Your browser is already open. Let your AI help you finish the task.

MyChrome connects a local MCP client such as Codex or Claude Code to your signed-in Google Chrome on an Apple Silicon Mac. Read a page, fill in details and check the result without moving the work to a separate browser session. Double Esc returns control. Save suitable repeated steps as website routines and provide fresh values for the next run.

Start with the guided source installer and a small offline practice task. MyChrome is open source under MIT. It requires macOS 13+, Google Chrome, supported Node.js and Xcode Command Line Tools. Claude browser tools are supported; Claude live text and direct replies in the native window are not available.

## 中文简介

浏览器已经打开，让 AI 帮你把事情做完。

MyChrome 把 Codex、Claude Code 等本机 MCP 客户端连接到你正在使用的 Chrome，保留已登录页面和工作上下文。让 AI 读取、填写、选择并核对结果，快速连按两次 Esc 即可收回控制；合适的连续步骤还能保存为网站流程，下次填写新参数后运行。

项目采用 MIT License，支持 Apple Silicon Mac、macOS 13+，需要 Google Chrome、受支持的 Node.js 和 Xcode Command Line Tools。跟随源码安装引导，从内置离线练习开始。Claude 浏览器工具可用；原生窗口暂不支持 Claude 实时文字及直接回复。
