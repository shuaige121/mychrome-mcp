# 网站流程

[首页](../README.zh-CN.md) · [使用说明](usage.zh-CN.md) · [AI 操作指南](ai-guide.md)

网站流程把已经执行过的连续网页操作保存下来。下次填写新参数、选择现有标签页，即可按保存的步骤运行。查找重复片段、保存、界面操作和流程执行都不需要额外调用模型；执行时仍使用 MyChrome 原有的真实键鼠、安全检查和共享输入队列。

## 从记录保存流程

1. 打开 MyChrome，选择「网站流程」，再选择操作连接。没有可用 MCP 连接时，界面会显示未连接。
2. 自动记录默认开启。让 AI 正常完成获准的网页操作后，在这里刷新并选择网站。
3. 在「最近记录的操作」选择开始和结束步骤，或选择一个「可复用片段」。手动选择按记录顺序包含中间全部步骤。
4. 检查片段，输入名称并保存。保存的流程显示步骤和运行次数；点击可查看详情，暂时不用时可归档。

一个流程最多 50 步，必须来自同一会话、标签页、网站、任务和连续录制区间。网站按完整 origin 分组，包含协议和非默认端口。其他会话穿插的记录不会混入选中片段；选中会话本身的失败、未完成、敏感目标、不支持的操作或漏记动作仍会阻断序列，不能省掉中间步骤再拼接。重复建议来自记录中的相同连续片段，不是模型猜测的计划。

## 在现有标签页运行

1. 打开保存的流程，检查动作和目标。先在 Chrome 回到录制的起点，并确认当前账号和本次操作范围。
2. 填写本次参数。输入正文与下拉选项值没有被保存成默认值，因此每次都要重新提供。
3. 点「读取标签页」，明确选择一个现有标签页。界面不会自动新开页面，也不会默认选择最前面的页面。
4. 点「运行流程」。界面显示正在执行的步骤、已确认步数和结果；页面或目标变化时停止，保留已执行部分。

「操作设置」中用户固定的逐字或粘贴方式优先于流程参数，速度和全局暂停也继续生效。跟随任务模式默认逐字输入 ASCII；不支持的字符不会自动改成粘贴。执行不会用 DOM 写值或脚本点击替代真实输入。

接管键鼠时，在 **0.8 秒内连按两次 Esc** 可立即停止；此时鼠标被拦截，不能依赖点击 GUI 按钮。「停止流程」按钮可在接管前或键鼠归还后使用，发出请求后等待状态确认。全局「暂停 AI 操作」用于阻止各连接继续输入。停止不能撤销已送出的点击、文字或提交，重新运行前需要检查页面。

「检查状态」查询原运行。正常热更新后，GUI 只读查询同一 launcher、同一安装来源的可信后继连接；仅在原 nonce、已知 run ID、流程和标签都匹配且回执已结束时恢复结果，不重新执行。没有可信回执时继续显示待确认；仍可切换连接查看其他记录或前往设置，原请求身份会保留，新运行保持禁用，避免重复操作。

| 状态 | 含义 |
|---|---|
| 流程运行中 | 本次运行仍在执行、核对或归还控制。 |
| 本次流程已完成 | 保存的步骤已执行并通过对应检查。提交的业务结果仍需另外核对。 |
| 流程已停下，需要处理 | 页面、目标或操作结果未满足检查，后续步骤未继续。 |
| 流程已停止 | 本次运行已取消。已执行部分不会回滚。 |
| 流程未完成 | 启动或收尾出现明确失败。 |
| 运行状态尚未确认 | 没有可靠回执；继续查询原连接，不自动重启。 |

流程终态只描述这次保存步骤的运行。如果它属于 AI 更大的任务，不会据此宣告整个任务结束。

## MCP 调用与重复请求

使用 `routines` 工具，所有例子的 ID 都须替换成当前工具返回的真实值。

| action | 主要参数和结果 |
|---|---|
| `snapshot` / `list` / `history` | 可传 `site`、`query`、`limit`；返回网站、操作、保存的流程和候选片段。 |
| `save` | `name`、可选 `description`、正序的连续 `eventIds`。候选片段的 `eventIds` 可直接使用。 |
| `update` | `id`，以及 `name` 或 `archived`。 |
| `settings` | `enabled`，控制后续自动记录。 |
| `tabs` | 列出可明确选择的现有 Chrome 标签。 |
| `start` / `run` | `id`、`tab`、`params`、`nonce`。`start` 立即返回；`run` 等待执行结果。 |
| `status` | 原来的 `runId` 或 `nonce`。 |
| `stop` / `cancel` | 原来的 `runId` 或 `nonce`，请求停止该次执行。 |

```json
{"action":"start","id":"returned-routine-id","tab":123,"params":{"input_1":"sample search","option_1":"Practice"},"nonce":"unique-run-intent-01"}
```

`params` 的键必须来自保存流程的 `parameters`，不能假设每个流程都有例子中的两项。每个值都是本次输入的字符串。GUI 的完整请求上限为 128 KiB UTF-8 JSON，包含参数和请求字段；中文通常占用多个字节。界面会在发送前拒绝超限请求，并明确显示「未发送」，不会留下不确定的运行。

一次运行意图只用一个 nonce，同时保留 worker、流程、标签和参数。相同 nonce 和请求体不会再启动一份执行；修改请求体却沿用 nonce 会被拒绝。收到超时或断连时，先按原 nonce 查状态或停止，不能换 nonce 再发。

正常代码热更新会移交已经结束的运行回执和请求签名，不携带输入参数；等待启动或正在执行时不切换 worker。进程崩溃、普通重启等没有回执移交的情况不支持自动重试。此时 `run_not_found` 不能证明原操作从未发生。只有检查了原运行和页面，明确要执行新的一次流程时才生成新 nonce。

## 本机记录和适用边界

记录保存在 MyChrome 设置目录旁的 `routines` 目录，可用 `CHROME_BRIDGE_ROUTINES_DIR` 指定专用位置。自动记录开关关闭后保留已有记录和保存的流程；重新开启后的记录不会跨越关闭区间组成序列。它与「我的操作习惯」节奏采样、简要活动记录是独立功能。

记录包括经过筛选的网站路径、控件描述、操作顺序、布尔状态检查和结果；输入正文、下拉选项值、密码和验证码不会作为重放参数保存。符合条件的 URL 查询值仅保留身份 hash，用于区分看似相同的页面。可识别的敏感目标和秘密 URL 会被拒绝重放。路径、标签和流程名仍可能说明使用过的网站与业务，应留在本机；不要把该目录上传到代码仓库。界面不会读取浏览器历史或 AI 会话历史来补全动作。

当前可保存符合条件的点击、悬停、输入、原生下拉选择、按键和滚动。它不是任意网站的通用录制器：

- iframe、shadow DOM、canvas 和无法唯一确定的控件暂不支持流程重放；坐标点击和对话框处理不会被拼成可重放步骤。
- 支持符合检查的 `#/path`、`#!/path` 路由。普通锚点或其他非标准 hash 状态暂不支持，避免遗漏页面身份后操作错误页面。
- 页面来源、路径、查询身份或目标不匹配时停止；已标记的敏感目标、网站验证和访问限制仍须人工处理。
- 记录失败会显示提醒并留下序列缺口，后面的动作不能越过缺口组成流程。存储不可用不应改变普通获准操作本身的结果。
- 步骤通过检查不保证外部业务已经成功。付款、提交、发消息等动作仍须在用户授权范围内，执行后检查网站实际结果。

离线测试验证的是合成条件下的代码行为；三步重放、输入停止和 GUI 的实机验收使用受控的本地测试页面。特定网站能否完整运行，仍需要该网站上的实际验收。版本验收范围见 [发布记录](release/CHANGELOG.md)。
