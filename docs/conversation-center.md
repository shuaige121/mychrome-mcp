# 会话中心

MyChrome 的原生 macOS 窗口可以新建 Codex、Claude Code 对话，也汇总本机已连接 MyChrome 的 AI 会话。点击菜单栏图标，再点「打开会话中心」；也可以运行：

```sh
npm run gui
```

从源码完成 build 后，运行 `npm run install:gui` 会将已编译的原生程序复制到 `~/Applications/MyChrome.app`，之后可从 Finder 或 Spotlight 打开会话中心。App 运行仍依赖当前 checkout，请保留该目录。它不修改 AI 客户端配置。

更新源码后，重新 build 并安装，才能更新 App 内的程序：

```sh
npm run build
npm run install:gui
```

## 从 App 新建对话

点击「新对话」，选择 Codex 或 Claude Code。选中的 CLI 必须已在本机安装并登录；MyChrome 使用它已有的账号、操作权限和 MCP 配置。

模型列表及每个模型支持的思考强度由本机 CLI 动态返回。选择模型、强度和工作目录后，可直接创建空对话，也可填写第一条任务。选择只作用于这个会话，不写入客户端的持久配置。工作目录决定客户端加载的项目上下文与项目配置。

创建后会自动打开准确对应的对话，第一条任务通过同一套发送与回执流程提交。创建结果暂不确定时，「检查创建结果」核对同一次请求，不会另开一个对话。首条任务发送结果不明时，草稿保留在对应会话中，不自动重发。

App 创建的 Codex 和 Claude Code 会话都能在右侧显示实时文字、输入下一条消息及回答结构化问题。支持的授权请求会单独显示待审阅动作；内容无法充分展示时不能批准。授权只对应当前请求，不保存后续自动允许规则。

「停止生成」中断选中会话当前的工作，不撤销已经发生的操作。关闭窗口或退出 MyChrome 不会终止这些后台会话；重新打开 App 后可以连接仍在运行的会话。后台进程退出后，当前版本不自动恢复它，也不会另开会话冒充原对话。草稿仍只保存在 App 内存中，退出 App 会清除未发送内容。

## 找到正在做的事

窗口顶部用「对话 / 操作设置」切换，旁边可暂停或继续 AI 操作。对话页只放会话列表、实时进展和回复；可按列表标题或 AI 类型搜索。

左侧优先显示真实对话标题，没有标题时显示当前任务。AI 类型放在副标题；目录名和进程编号不再占据列表。需要回复或网页接手的任务排在最前。

未关联、空闲且没有草稿的连接默认收在「未关联的连接」里，点击可以展开。「添加对话」会列出对应 Codex 宿主实际已加载的对话供选择，不猜测终端任务。当前选中、正在执行、有草稿或送达待确认的连接保持可见。同名会话通过连接时间辅助区分，完整连接信息可在行上悬停查看。

关闭窗口不会退出 MyChrome；再次从 Finder 或 Spotlight 打开 App，会重新显示会话中心。

状态颜色在列表、会话详情和发送回执中保持一致，并配有文字与图标：蓝色表示正在运行，橙色表示等待你处理或送达结果不明，红色表示明确失败，灰色表示空闲、未接入或断连。绿色「回复已送达」只来自宿主确认，不代表整个任务完成。正文保持原文，消息结束也不会被推断成任务成功。

## 跳到需要你的地方

网页要求人工处理时，MyChrome 显示可点击提示。点「去处理」会定位到这次等待对应的 Chrome 标签；点「查看会话」会打开对应会话。提示本身不会切换前台。

会话中心会显示正在排队、已定位、提醒过期、暂停、占用或失败的结果。旧提醒、已经换过的会话、页面已经变化或等待已经结束，都不会被当成当前任务执行。全局暂停和其他 agent 正在操作时的输入锁仍然生效。

网页登录、验证码和私密字段仍在原网页处理。GUI 中给 AI 的一句回复不会被当成网页已经完成操作。

## 直接回复 AI

如果连接没有携带对话 ID，点击「关联对话」，从当前 Codex 宿主实际已加载的对话中选择。列表只读取标题和状态，不打开历史记录。

支持的会话可在右侧直接回复，`⌘ Return` 发送，`Return` 换行。外部已关联的 Codex 对话经本机 daemon 定向发送到该 thread；App 新建的对话通过其独立 CLI 连接发送。Codex 在执行中可接收补充指令；Claude Code 需等待当前一轮结束后再发送下一条，执行中可以停止生成或回答当前问题。发送按钮跟随实际会话状态启用。

Codex 发出的结构化问题会显示选项和输入框。提交使用原问题的 request ID。其他客户端也可能同时回答同一问题，因此问题结束不等于能确认采用了 GUI 的回答；界面会明确显示这种情况。权限审批不被当作普通问答。

仅显示接入后 AI 已公开展示的自然语言进展，不读取历史对话文件，不展示内部推理或工具命令。刚连接到正在运行的会话时，需要等一个实时事件确认当前 turn，发送按钮才会启用。

**外部已经运行的 Claude Code 会话仍不能关联到这里查看实时文字或直接回复；请在原客户端继续，或通过「新对话」建立独立的 App 会话。** 这些外部连接仍支持浏览器工具和网页接手。MyChrome 不会向前台终端盲打；没有绑定到明确 thread 的连接不能发送。

GUI 中已验证的 Codex 关联也可供长任务侧栏使用。更新同一个任务时省略对话 ID，不会断开原来源；GUI 切换到另一对话时，原任务继续观察自己的来源。短暂断线会有限重连，只接收新的公开消息，不补读历史。送达结果不明时保留原连接账本，不自动重发。

## 草稿与送达状态

每份草稿绑定到具体会话及连接版本。连接变化后可从「保留的草稿」找回，不会自动转投到新会话。草稿只保存在本机内存，退出 MyChrome 后清除。

文字只经本机私有 socket 和标准输入传输，不放在命令参数或 presence 文件里。发送成功需宿主回执；断线后无法确认时，保留原提交编号和内容。「检查送达状态」只查询已有结果，不重新发送。确认过原会话后，用户可解除等待并输入下一条回复。

当前窗口汇总 App 创建的会话，以及已连接 MyChrome 的外部会话，不代表电脑上所有终端或 AI 对话。

## 操作设置

「输入方式」有三项：跟随任务（默认，由工具选择，未指定时逐字输入）、逐字键盘输入、直接粘贴。用户固定的方式优先于 AI 工具参数。逐字模式仅支持 ASCII 键盘字符；中文等内容在任何输入前被拒绝，需要选择粘贴。原生日期和时间控件需要逐键输入，粘贴模式会明确拒绝。

「操作速度」提供 0.5×、0.75×、1×、1.5×、2×、3×，调整按键、鼠标及滚动节奏。下一个动作会读取新设置，无需结束长任务；接管时 ↑ / ↓ 使用同一份设置。客户端环境变量固定的项目会显示来源并禁用修改。

窗口位置、通知及操作习惯采样也集中在这一页。操作习惯采样记录键鼠节奏的汇总，与做题视频录屏分开。App 使用安装目录中的录制助手；退出 App 会取消尚未完成的习惯采样。已有汇总的路径和格式保持不变。
